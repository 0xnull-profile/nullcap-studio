## Overview

NullCap Studio is a privacy-focused network forensics
and investigation workspace designed for local analysis
of network capture files.

## Available Editions

| Edition | Platform | Access |
|---|---|---|
| Standalone | Modern web browser | [Launch Web App](https://0xnull-profile.github.io/nullcap-studio/) |
| Portable | Windows x64 | [Download EXE](https://github.com/0xnull-profile/nullcap-studio/releases/download/v4.0.1/NullCap-Studio-4.0.1-win-x64.exe) |

## Core Capabilities

- PCAP and PCAPNG analysis
- Interactive network topology
- Packet and conversation inspection
- TCP stream reassembly
- Network artifact analysis
- Forensic workspace management
- Evidence organization
- Investigation dossier export
- Dark Professional interface
- Premium Glow iconography

## Privacy

Network capture processing is performed locally.
No application backend or user account is required.

The Windows Portable Edition can operate offline.

See [PRIVACY.md](PRIVACY.md) for further information.

## Windows Portable Edition

No installation required.

The executable is not digitally signed.
Windows SmartScreen may display a warning.

Verify the downloaded executable using the SHA-256
checksum provided with the official release.
