# Segnalazione di vulnerabilità

Non pubblicare dettagli sfruttabili, catture reali, credenziali, token o evidenze riservate nelle issue pubbliche. Utilizzare la segnalazione privata di vulnerabilità GitHub (Security > Report a vulnerability), se abilitata dal manutentore. Se non è disponibile, richiedere un canale privato al manutentore senza includere dettagli sensibili.

Includere versione, ambiente, descrizione del problema e una riproduzione minima con dati sintetici. Non inviare dati personali o acquisizioni reali. Non è definito un SLA di risposta.
