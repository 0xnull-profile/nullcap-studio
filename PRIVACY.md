# Privacy e dati investigativi

NullCap è progettato per elaborare localmente le catture nel browser, senza un servizio di analisi remoto. Il comportamento di browser, estensioni, sincronizzazione, sistema operativo e strumenti esterni non è sotto il controllo dell'applicazione. Per dati riservati usare un ambiente controllato, eventualmente disconnesso dalla rete.

Le catture, gli artefatti, le annotazioni, i report e gli archivi esportati possono contenere indirizzi, identificativi, contenuti e altri dati sensibili. Non pubblicarli in issue o repository. Conservare originali ed esportazioni secondo le regole dell'indagine; controllare i file prima di condividerli. Eliminare i file esportati e gli eventuali dati del browser secondo le procedure del proprio ambiente.

## GitHub Pages

Il caricamento iniziale del sito richiede una connessione e può comportare il trattamento di metadati di accesso da parte del servizio di hosting. Per attività riservate usare il pacchetto locale in un ambiente controllato.
