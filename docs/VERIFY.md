# Verify / Verifica

NullCap Studio 4.0.1 — 0xnull-profile

Extract the complete standalone ZIP, retaining the accompanying license notices. From the extracted directory run `sha256sum -c SHA256SUMS.txt`. In PowerShell run `Get-FileHash -Algorithm SHA256 -LiteralPath .\NullCap-Studio-4.0.1.html` and compare with the trusted official manifest. The manifest is unsigned and does not authenticate the publisher. Reject mismatches.
